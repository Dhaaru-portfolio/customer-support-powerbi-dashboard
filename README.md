# 📊 Customer Support Ticket Analysis - Power BI Dashboard

## 🔍 Project Overview
Built an interactive Power BI dashboard to analyze customer support tickets from Kaggle dataset. This project helps businesses identify bottlenecks, track agent performance, and improve customer satisfaction.

## 🎯 Key Business Questions Answered
- Which type of issues are most frequent?
- What is the average resolution time?
- Which agents are top performers?
- When do we get peak tickets? (Trend Analysis)
- What is our CSAT Score?

## 📈 Dashboard Features & KPIs
- **Total Tickets:** 8.5K+ 
- **Avg Resolution Time:** 2.3 Days
- **CSAT Score:** 4.2/5
- **Top Issue Category:** Technical Support
- Interactive filters: Date, Priority, Agent, Category

## 🛠️ Tools & Skills Used
- Power BI Desktop & DAX
- Power Query (Data Cleaning & Transformation)
- Data Modeling
- Data Visualization & Storytelling
- Excel / CSV

## 📁 Repository Structure
- `CUST_SUPPORT_DASHBOARD.pbix` - Main Power BI File
- `raw_data.csv` - Original Kaggle Dataset (To be added)
- `/screenshots` - Dashboard preview images

## 🚀 Insights Found
1. 60% of tickets were related to Delivery & Technical issues
2. High Priority tickets take 30% longer to resolve
3. Customer satisfaction dropped during festival season due to delay
